# 站点管理

管理漫画源站点（爬虫站点），支持增删改查、批量操作和导入。

## 站点信息

每个站点卡片显示：

- **站点名称**和 URL
- **在线状态**：绿色在线 / 橙色异常 / 红色离线
- **分类标签**：漫画 / 漫画18
- **能力标签**：下载、刮削
- **统计数据**：响应时间、成功率、最后检测时间

## 常用操作

| 操作 | 说明 |
|------|------|
| 检测站点 | 测试站点是否可访问，更新响应时间和成功率 |
| 编辑站点 | 修改站点信息和认证配置 |
| 删除站点 | 删除站点（需二次确认） |
| 导入站点 | 通过 JSON 文件 URL 批量导入站点数据 |
| 批量检测 | 选中多个站点后批量执行检测 |
| 批量删除 | 选中多个站点后批量删除 |

## 认证配置

站点支持四种认证方式：

- **无需认证**：公开站点
- **Basic 认证**：用户名 + 密码
- **Cookie 认证**：粘贴 Cookie 文本自动解析为键值对
- **Token 认证**：配置请求头键值对

## 筛选

- 按站点 URL 或备注搜索
- 按分类过滤（漫画 / 漫画18）
