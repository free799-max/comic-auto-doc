# 漫画探索

漫画探索是系统默认首页，聚合多个漫画平台的排行榜数据，帮助你发现和订阅新漫画。

## 支持的漫画源

| 漫画源 | 说明 |
|--------|------|
| 腾讯漫画 | 排行榜、分类榜 |
| 哔哩哔哩漫画 | 热门榜、新作榜 |
| 快看漫画 | 热度榜 |
| Toomics | 热门排行 |
| Toptoon | 热门排行 |

## 使用方式

1. **切换漫画源**：点击顶部的圆点标签栏，选择不同漫画平台
2. **切换榜单**：根据当前漫画源，选择不同的榜单类型（热门榜、新作榜等）
3. **浏览漫画**：网格布局展示漫画封面，前三名有金、银、铜排名角标
4. **查看详情**：点击漫画卡片弹出详情，包含作者、来源、分类、简介、标签、连载状态
5. **一键订阅**：点击卡片右下角的心形图标即可订阅
6. **搜索漫画**：点击卡片左下角的搜索图标进入搜索页

::: tip 云端榜单
高级版及以上用户，本地暂无榜单数据时会自动从云端拉取官方维护的榜单，数据更全、更稳定。
:::
