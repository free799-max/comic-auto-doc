# 客户端

## 已完成功能

### 🔐 用户认证

- JWT Token 登录认证（Access Token 14 天有效期）
- Token 刷新机制（Refresh Token）
- Token 有效性验证接口
- 用户能力权限返回（abilities 字段）

### 📚 订阅管理

订阅是系统的核心功能，实现漫画的自动化追踪和下载：

- **CRUD 操作**: 创建、查询、更新、删除漫画订阅
- **自动更新检查**: 定时检查订阅漫画是否有新章节
- **智能站点择优**: 多站点按可用性、响应时间、章节数排序，自动选择最优源
- **CBZ 打包**: 下载的章节图片自动打包为 CBZ 格式，兼容主流漫画阅读器
- **元数据刮削**: 从第三方平台获取作者、标签、简介等信息
- **封面同步**: 自动下载并更新漫画封面到媒体库

### 🌐 站点管理

监控爬虫站点的健康状态：

- **可用性检测**: 批量检测各爬虫站点是否可访问
- **响应时间监控**: 记录每个站点的平均响应耗时
- **异步检测**: 支持 Celery 异步执行，避免阻塞请求
- **分类过滤**: 按漫画类型（国漫/韩漫/日漫）筛选站点

### 📺 媒体库集成

支持 Komga 和 Kavita 两种主流漫画媒体服务器：

- **多服务器支持**: 可同时配置和管理多个媒体服务器实例
- **元数据同步**: 自动更新漫画的标题、作者、标签、简介等元数据
- **封面更新**: 同步漫画封面图片到媒体库
- **库扫描触发**: 下载完成后自动通知媒体服务器扫描新文件
- **连接测试**: 提供接口验证服务器配置是否正确
- **统一抽象**: 通过工厂模式 `get_enabled_servers()` 统一调用不同平台 API

### 🔍 探索发现

聚合多平台漫画榜单，帮助用户发现新漫画：

**支持平台：**
- 腾讯漫画（排行榜、分类榜）
- 哔哩哔哩漫画（热门榜、新作榜）
- 咚漫（人气榜、新作榜）
- 快看漫画（热度榜）

**特性：**
- 数据聚合：统一数据结构，支持跨平台对比
- 榜单类型：周榜、月榜、总榜等多种时间维度
- 分类筛选：按漫画类型（国漫/韩漫/日漫）过滤

### ⏰ 任务调度

可视化的 Celery Beat 定时任务管理：

- **任务列表**: 查看所有已注册的定时任务
- **手动触发**: 无需等待定时，直接执行任务
- **执行历史**: 记录每次任务的执行状态和结果
- **执行时长**: 统计任务运行耗时
- **下次执行时间**: 显示任务的下次调度时间
- **WebSocket 推送**: 任务执行进度实时推送到前端

### 🕷️ 爬虫系统

模块化的漫画爬虫框架：

- **国漫爬虫**: 支持 acqq（腾讯漫画）、bakamh 等站点
- **韩漫爬虫**: 支持 manhuadb 等站点
- **刮削器**: 独立的元数据刮削模块，从第三方平台获取漫画详情
- **统一接口**: 所有爬虫继承 `CrawBase` 基类，实现标准化接口
- **动态加载**: 通过 `importlib` 按需加载爬虫模块

### 📱 移动端支持

- **PWA**: 支持添加到主屏幕，离线缓存
- **Android App**: 基于 Capacitor 打包原生应用
