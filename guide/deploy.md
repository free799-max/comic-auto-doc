# 部署概览

Comic Auto 支持多种部署方式，你可以根据实际环境选择最合适的方案。

## 部署方式对比

| 方式 | 适用场景 | 复杂度 | 推荐度 |
|------|----------|--------|--------|
| [Docker Compose](/guide/deploy-docker) | 生产环境、服务器部署 | 低 | ⭐⭐⭐⭐⭐ |
| [PM2 进程管理](/guide/deploy-backend) | 开发环境、轻量服务器 | 中 | ⭐⭐⭐⭐ |
| [手动部署](/guide/deploy-environment) | 学习调试、自定义环境 | 高 | ⭐⭐⭐ |

## 推荐生产部署方案

### 方案一：Docker Compose（推荐）

所有服务容器化编排，一键启动：

```bash
cd /opt/comic-auto
docker compose up -d
```

**优势：**
- 环境隔离，避免依赖冲突
- 快速启动和扩容
- 便于备份和迁移

### 方案二：PM2 + Nginx

适合已有运行环境的服务器：

```bash
# 后端
pm2 start ecosystem.config.js

# 前端
npm run build
# Nginx 配置静态目录
```

**优势：**
- 资源占用更低
- 更灵活的调试
- 适合开发和测试环境

## 部署前准备

无论选择哪种方式，都需要先完成以下准备：

1. [环境准备](/guide/deploy-environment) - 安装系统依赖
2. 数据库初始化 - PostgreSQL 和 Redis
3. 配置文件设置 - 环境变量和系统配置

## 首次部署检查清单

- [ ] PostgreSQL 数据库已创建并配置用户权限
- [ ] Redis 服务已启动
- [ ] 后端 `poetry install` 完成
- [ ] 数据库迁移 `python manage.py migrate` 执行成功
- [ ] 管理员账号 `python manage.py createsuperuser` 已创建
- [ ] 前端 `npm install && npm run build` 成功
- [ ] Nginx 反向代理配置正确
- [ ] 媒体服务器（Komga/Kavita）可选配置
