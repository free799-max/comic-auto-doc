# 任务管理

管理定时任务和查看执行历史。

## 定时任务

以表格形式展示所有已注册的定时任务：

| 字段 | 说明 |
|------|------|
| 名称 | 任务名称 |
| 调度规则 | Cron 表达式或间隔时间（中文友好显示） |
| 状态 | 已启用 / 已禁用 |
| 上次执行 | 最近一次执行时间 |
| 累计次数 | 历史执行总次数 |
| 下次执行 | 下一次调度时间 |

### 任务操作

- **运行**：手动立即执行任务
- **日志**：查看任务执行日志
- **编辑**：修改任务调度配置
- **筛选**：按启用状态过滤（全部 / 已启用 / 已禁用）

## 执行历史

记录每次任务的执行情况，支持以下筛选条件：

- **任务名称**：下拉选择具体任务
- **执行状态**：成功 / 失败 / 执行中 / 等待中 / 已撤销
- **日期范围**：支持快捷选择（今天、最近 7 天）

表格展示：任务名、状态（彩色标签）、开始时间、完成时间、执行时长，点击可查看日志详情。
