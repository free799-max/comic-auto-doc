# 系统设置

系统全局配置，分为三个模块。

## 基本设置

### 基础配置

| 配置项 | 说明 |
|--------|------|
| 缓存目录 | 漫画缓存文件存储路径 |
| 下载目录 | 漫画下载文件存储路径 |
| 缓存限制 | 缓存占用上限（GB） |
| 缓存时长 | 缓存保留天数 |
| 代理设置 | 启用代理并配置地址（http/https/socks5），支持代理检测 |

### API 密钥

用于第三方客户端访问的 API 密钥，支持生成、复制和重置。

### 许可授权

管理软件许可证：

- 输入许可证密钥激活
- 查看激活状态（未激活 / 已激活 / 已过期 / 已暂停）
- 查看订阅到期时间
- 解除机器绑定

## 媒体服务器

配置 Komga 或 Kavita 媒体服务器，实现漫画自动同步到媒体库。

| 配置项 | 说明 |
|--------|------|
| 服务类型 | Komga / Kavita |
| 服务地址 | 服务器 URL |
| API Key | 服务器 API 密钥 |
| 媒体库目录 | 选择漫画存储目录（支持远程浏览） |
| 刮削库 | 配置需要自动刮削元数据的媒体库 |

添加服务器前可先测试连接是否正常。

## 通知管理

管理系统通知渠道和发送记录：

- **全局配置**：通知总开关和通用设置
- **渠道管理**：添加和编辑通知渠道
- **发送记录**：查看历史通知发送情况
